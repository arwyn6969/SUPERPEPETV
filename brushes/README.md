# brushes

Source art lives upstream. This folder is not part of the objkt zip.

The sixteen actors shipped in `brushes.js` are 64×64 PNG data URIs already
curated by SUPERPEPEPAINT from PEPEPAINT V1 (MIT, Nathan Gregg). Several
original files in `arwyn6969/SUPERPEPEPAINT/brushes` are 200–900KB. Do not
copy that folder into the NFT zip.

- PEPEPAINT V1 — https://github.com/nathansonic/PEPEPAINT-V1
- SUPERPEPEPAINT — https://github.com/arwyn6969/SUPERPEPEPAINT
